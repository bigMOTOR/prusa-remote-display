# Prusa Remote Display 1.0.1

Fixes rejection of GitHub release download links whose signed query contains an
encoded slash. HTTPS, the exact GitHub host and asset path, one CDN redirect,
download limits and signed-image verification remain required.

The same URL defect is present in 1.0.0 and earlier installed firmware. Those
versions may be unable to fetch this update over the air and need a USB recovery
step. The browser installer performs an initial installation and erases saved
display settings; do not use it expecting a settings-preserving update.

This release changes no display UI, pairing or printer configuration. The
supported board remains Waveshare ESP32-S3-LCD-2.8 **non-touch**.
