# Prusa Remote Display 1.1.1

Fixes over-the-air updates from GitHub.

Versions 1.0.x and 1.1.0 can't download updates because of this bug. This one time, install 1.1.1 by USB with the browser installer — it erases saved settings, so set up Wi-Fi and PrusaLink again. From 1.1.1 on, updates install over the air from the display.

The supported board remains Waveshare ESP32-S3-LCD-2.8 non-touch.
