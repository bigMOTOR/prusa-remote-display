# Prusa Remote Display 1.1.1

Fixes GitHub OTA downloads failing on long release download addresses. HTTPS,
GitHub URL restrictions and signed-image verification remain required.

Installed versions 1.0.x and 1.1.0 cannot download this update over the air.
Install 1.1.1 by USB with the browser installer, which erases saved display
settings. Set up the display again after installation.

The supported board remains Waveshare ESP32-S3-LCD-2.8 **non-touch**.
