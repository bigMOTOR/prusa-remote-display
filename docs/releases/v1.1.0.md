# Prusa Remote Display 1.1.0

Remaining print time is easier to read: `2h42m left` replaces `2:42`.
When printer data gets stale, the normal screen shows `Last update` with an age
such as `21 sec ago`. The error screen uses `Updated 21 sec ago`.
Transitions between normal and error screens are smoother.

GitHub now has a **Bug report** form for problems and an **I built one** form
for sharing your build, photos and feedback on the instructions.

From 1.0.1, update over the air from the display. From 1.0.0, connect by USB
and use the browser installer. The browser installer erases saved display
settings, so you will need to set up the display again.
