# Prusa Remote Display 1.0.0

Your print, at a glance. A small local-network display built and tested for the
Prusa CORE One with PrusaLink, using the Waveshare ESP32-S3-LCD-2.8 **non-touch**
board and a printed enclosure.

- Follow printing progress, pause, completion and printer errors without opening
  your phone. The display can sleep after a completed print.
- Set up Wi-Fi and PrusaLink locally. Your Wi-Fi password and printer key belong
  on the display's setup page; they are never entered on the installation site.
- Install ready-made firmware from desktop Chrome or Edge with a USB data cable.
  Initial installation erases saved display settings and does not change the printer.
- Firmware updates are offered for confirmation; the display does not install an
  update without your choice. Routine monitoring stays on your local network.

[Build and setup guide](https://github.com/bigMOTOR/prusa-remote-display/blob/v1.0.0/docs/get-started.md)
· [Browser installer](https://bigmotor.github.io/prusa-remote-display/)
· [Installation and recovery](https://github.com/bigMOTOR/prusa-remote-display/blob/v1.0.0/docs/installation-and-recovery.md)
· [Source archive](https://github.com/bigMOTOR/prusa-remote-display/releases/download/v1.0.0/prusa-remote-display-1.0.0-source.tar.gz)

Use only the supported non-touch board. The touch model and other ESP32-S3
boards are not supported. PrusaLink compatibility details and local-network
requirements are in the setup guide. Safari can read the guide but cannot install
firmware over USB.
