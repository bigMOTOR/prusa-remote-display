# Release notes

`v1.1.0.md` is the proposed next release body. The frozen `v1.0.0.md` and
`v1.0.1.md` remain unchanged history. Publish only after all applicable digital gates, source/notices accompaniment
and owner approval of the exact candidate. First actual GitHub delivery and
physical OTA verification follow publication of the public stable release; they
remain open until observed. A local fix and passing tests do not establish
physical OTA acceptance. Check release links anonymously after publication; the Pages address serves the most
recent owner-approved deployment.
Keep the target version synchronized with firmware/version.txt and both installer
package manifests. Desktop preview dependencies keep their independent versions.
