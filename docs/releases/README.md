# Release notes

`v1.0.0.md` is the proposed release body. Its URLs are exact intended destinations,
not evidence that the release, source asset or Pages site exists today. Publish
only after owner approval of the frozen build, source/notices accompaniment and
all prerequisites for that separately approved publication. First official
GitHub delivery is verified after the first public stable release under its
separate owner approval; that release does not itself establish final accepted
v1. Final v1 acceptance and Printables publication wait for the required delivery
and physical/recovery results. This ordering waives no other physical gate and
does not change the accepted release level. Check every link anonymously after
publication; the Pages address always serves the most
recent owner-approved deployment, while the source and guide links are versioned.
Keep the target version synchronized with firmware/version.txt and both installer
package manifests. Desktop preview dependencies keep their independent versions.
