# Application icon

`app-icon.png` is the functional installer icon, generated for this project on
2026-10-05 using the built-in image generation tool. It is distributed with the
original application software under GPL-3.0-only; it is not a third-party logo
and does not claim affiliation with Prusa Research. Keep the transparent source.
Platform icon containers are generated during packaging rather than hand-edited.

The final prompt requested a single polished desktop installer icon: a rounded
graphite tile, ivory physical display silhouette, orange progress bar and status
dot, readable at 32 pixels, transparent outside the tile, no lettering, faces,
printer-brand logos or unrelated objects. The palette follows the application's
graphite, ivory and orange interface. No existing brand image was used as input.
