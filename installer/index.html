Before installing

Compatibility and installation details

Safari can show this guide, but cannot install over USB because it does not provide Web Serial. Use desktop Chrome or Edge for USB installation; iOS is not supported by this path. Chip detection cannot identify this exact board. Check its model before proceeding. Installation starts only after you choose a USB port and confirm in the installer.

2

Step 2: Connect to your printer

  1. After installation, follow the display's setup screen.
  2. Join its PRD-Setup-… Wi-Fi network with the password on the screen. Stay connected even if your phone says there is no internet.
  3. Open the address shown on the display, normally http://192.168.4.1.
  4. Check your home Wi-Fi, then enter your printer's local address and PrusaLink API key.

Your Wi-Fi password and printer key belong in that local setup page, not on this website. Normal monitoring does not use this site.

Buying and assembling the display

The enclosure and complete parts list are still being physically verified. This page is not yet a finished build-your-own kit. Do not substitute another board, force tight printed parts or press through an unsupported switch.
