# Validation evidence

Raw evidence (serial logs, photos, measurements) referenced by
[waveshare-esp32-s3-lcd-2.8.md](../waveshare-esp32-s3-lcd-2.8.md).

Naming: `YYYY-MM-DD-<short-topic>.<ext>`.

Before committing anything here (Bootstrap Spec §16.8): redact machine
paths, usernames and serial numbers; never include credentials, Wi-Fi names
or real printer payloads.
