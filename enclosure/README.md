# Display enclosure

For the **Waveshare ESP32-S3-LCD-2.8 non-touch** board.
Start with the [printing guide](printing.md), then follow [cleanup and assembly](assembly.md).
There are four print groups: shell, rear cover, carrier and a cassette with a
moving button. The two printed nut keepers have been removed; the square M3 nuts remain.

- [3MF with part orientation and standard settings](3mf/display-enclosure.3mf).
- [STLs in print orientation](stl/).
- [STEP files in shared assembly coordinates](step/).
- [Editable source and export reproduction](source/README.md).

The photograph shows the current printed and assembled version, confirmed by
the project author on 3 November 2026. Only the two printed nut keepers were
removed from the print plate; the remaining geometry is unchanged.
A public release with ready-to-install firmware is not available yet.
